# SEA-Stack integration in `chrono_flap_sim`

## 1) What this enables

This integration wires the full hydrodynamics pipeline:

**SEA-Stack hydrodynamic forces (optional waves) → Chrono multibody flap dynamics → ROS 2 topics → ros2_control/HIL torque path**.

It works in both SIL and HIL modes, with runtime engage gating and safety clipping.

## 2) Prerequisites

- SEA-Stack built **and installed** locally. The install step is required —
  `SEAStackConfig.cmake` is shipped in the build tree but the matching
  `SEAStackTargets.cmake` is only generated by `cmake --install`. Pointing
  `SEAStack_DIR` at the build tree fails at configure time with
  `SEAStackTargets.cmake` not found.

  ```bash
  cd $HOME/SEA-Stack
  cmake --install build --prefix $HOME/SEA-Stack/install
  ```

- `SEAStack_DIR` (or `CMAKE_PREFIX_PATH`) set to the **install** tree:

  ```bash
  export SEAStack_DIR=$HOME/SEA-Stack/install/lib/cmake/SEAStack
  ```

  Easiest path: `source scripts/setup_env.sh` from this repo root.

- An OSWEC-compatible BEM `.h5` file.
- Recommended validation first: run SEA-Stack standalone OSWEC demo (`demos/oswec/demo_oswec_irreg_waves.cpp`) in SEA-Stack.

### Gotcha: colcon and `CMAKE_PREFIX_PATH`

colcon does **not** propagate the `CMAKE_PREFIX_PATH` *environment variable* into
CMake's `CMAKE_PREFIX_PATH` *variable*. As a result, exporting
`CMAKE_PREFIX_PATH` in your shell will not (by itself) let `find_package(SEAStack)`
discover SEA-Stack. This package's `CMakeLists.txt` works around this by
re-injecting `$ENV{CMAKE_PREFIX_PATH}` into `find_package`'s `PATHS` argument,
matching the existing VSG-discovery pattern. The workaround is silent on
success and equivalent to passing
`--cmake-args -DSEAStack_DIR=...` manually.

## 3) Build

`chrono_flap_sim/CMakeLists.txt` now uses:

```cmake
find_package(SEAStack QUIET CONFIG)
```

If found, build output prints that SEA-Stack was detected and compiles with `CHRONO_FLAP_USE_SEASTACK`. If not found, the package still compiles without SEA-Stack code paths.

For local Chrono workflow details, see [`docs/local-chrono-build.md`](docs/local-chrono-build.md).

## 4) Launching with SEA-Stack

`seastack_h5_path` defaults to empty (`""`), so SEA-Stack is **opt-in**.

### SIL

```bash
ros2 launch chrono_flap_sim sil_mode.launch.py \
  enable_visualization:=true \
  seastack_h5_path:=$HOME/SEA-Stack/build/data/demos/oswec/hydroData/oswec.h5
```

Optional calm/irregular toggles:

```bash
ros2 launch chrono_flap_sim sil_mode.launch.py \
  seastack_h5_path:=$HOME/SEA-Stack/build/data/demos/oswec/hydroData/oswec.h5 \
  wave_hs_m:=0.0 \
  hydro_torque_clip_nm:=0.2
```

### HIL

```bash
ros2 launch hil_odrive_ros2_control hil_mode.launch.py
```

Then pass SEA-Stack params directly to the node when launching (or via launch command overrides) using ROS args:

```bash
ros2 run chrono_flap_sim chrono_flap_node --ros-args \
  -p mode:=hil \
  -p seastack_h5_path:=$HOME/SEA-Stack/build/data/demos/oswec/hydroData/oswec.h5 \
  -p wave_hs_m:=0.0 \
  -p hydro_torque_clip_nm:=0.2
```

## 5) Engage gate and safety

SEA-Stack torque is gated by `~/enable_hydro`:

```bash
ros2 service call /chrono_flap_node/enable_hydro std_srvs/srv/SetBool "{data: true}"
```

Safety design:

1. Start disengaged by default.
2. Inspect raw hydrodynamic output first (`~/hydro_torque_raw`).
3. Engage when values look sane.
4. Hard-clip torque at `hydro_torque_clip_nm` before applying to Chrono body.

This is separate from the existing HIL engage and clamp path (defense in depth).

## 6) Telemetry topics

| Topic | Type | Publish behavior | Interpretation |
|---|---|---|---|
| `~/hydro_torque_raw` | `std_msgs/msg/Float64` | Every tick | SEA-Stack-requested Y-axis moment before clipping |
| `~/hydro_torque` | `std_msgs/msg/Float64` | Every tick | Applied Y-axis moment after clip |
| `~/wave_elevation` | `std_msgs/msg/Float64` | Every tick | Wave elevation at flap origin (or 0 for calm/no-wave) |
| `~/hydro_clip_engaged_pct` | `std_msgs/msg/Float64` | Every tick | Percent of last 100 ticks where clip activated |

## 7) Deliberate scale mismatch and expected ~100% clip on bench

The provided OSWEC `.h5` corresponds to a full-scale (~13-tonne-class) OSWEC
device, while this bench flap is ~0.21 kg acrylic. Raw SEA-Stack torques
(published on `~/hydro_torque_raw`) will be on the order of 10⁴–10⁶ N·m
because the BEM dataset describes a 26-metre offshore structure, not a
desk-sized hardware bench. The hard clip at `hydro_torque_clip_nm`
(default 0.2 N·m) is what makes the bench setup safe.

**Expected behaviour after `~/enable_hydro: true` with an unmodified OSWEC H5:**

- `~/hydro_torque_raw` is non-zero, possibly very large, possibly oscillating
  on the wave period
- `~/hydro_torque` is pinned to `±hydro_torque_clip_nm` almost continuously
- `~/hydro_clip_engaged_pct` sits near `100.0`

This is **not a bug** — it is the protective clip working exactly as designed.
The pipeline is healthy. To confirm: `~/hydro_torque_raw` is finite (not NaN
or ±inf), changes over time, and changes sign occasionally. Those three are
the proof the SEA-Stack → Chrono pipeline is alive.

A future follow-up is toy-scale BEM generation (e.g., Capytaine-based) and/or
a runtime `hydro_scale_factor` so the clip can be reduced while preserving
physical similarity at bench scale.

## 8) Parameter reference

| Parameter | Type | Default | Mutable at runtime | Notes |
|---|---|---:|---|---|
| `seastack_h5_path` | string | `""` | No | Empty disables SEA-Stack |
| `hydro_torque_clip_nm` | double | `0.2` | Yes | Must be `> 0`; forwarded to adapter |
| `wave_hs_m` | double | `0.0` | No | Calm sea default |
| `wave_tp_s` | double | `4.0` | No | JONSWAP peak period |
| `wave_seed` | int | `42` | No | Random phase seed |
| `wave_n_components` | int | `50` | No | Spectral discretization |
| `hydro_engaged_default` | bool | `false` | No | Initial state for `~/enable_hydro` gate |

## 9) Troubleshooting matrix

| Symptom | Likely cause | Action |
|---|---|---|
| SEA-Stack init says H5 not found | Bad/missing `seastack_h5_path` | Use absolute file path and verify file exists |
| `~/hydro_clip_engaged_pct` ~100% constantly | Clip too low for selected H5/waves | Lower waves (`wave_hs_m`) or increase clip cautiously |
| Hydro torque sign seems inverted | Body orientation/pivot-sign convention mismatch | Verify flap joint axis (`+Y`) and compare against known displacement tests |
| Build says SEA-Stack not found | `SEAStack_DIR` not exported to tree with `SEAStackConfig.cmake` | Export `SEAStack_DIR` and rebuild |
| `find_package(SEAStack)` finds `SEAStackConfig.cmake` but errors with `SEAStackTargets.cmake` not found | `SEAStack_DIR` points at SEA-Stack **build** tree instead of install tree | Run `cmake --install $HOME/SEA-Stack/build --prefix $HOME/SEA-Stack/install` and set `SEAStack_DIR=$HOME/SEA-Stack/install/lib/cmake/SEAStack` |
| CMake warning `Manually-specified variables were not used by the project: SEAStack_DIR` even though `find_package(SEAStack)` is in CMakeLists.txt | The PR adding SEA-Stack integration was not yet merged when you built; or you are on an older commit | `git pull --ff-only origin main` and rebuild |
| Setting `CMAKE_PREFIX_PATH` in `.bashrc` does not help `find_package(SEAStack)` find anything | colcon does not propagate `CMAKE_PREFIX_PATH` env var into the CMake var | This package re-injects `$ENV{CMAKE_PREFIX_PATH}` automatically. If still failing, `source scripts/setup_env.sh` or pass `--cmake-args -DSEAStack_DIR=$HOME/SEA-Stack/install/lib/cmake/SEAStack` |

## 10) Pipeline verification recipe

1. **Baseline without hydro**: launch SIL with empty `seastack_h5_path`; verify normal sim topics.
2. **Enable plumbing only**: launch SIL with `.h5`; keep hydro disengaged; verify non-zero `~/hydro_torque_raw` appears.
3. **Engage hydro**: call `~/enable_hydro true`; verify flap response tracks `~/hydro_torque` (clipped value).
4. **Enable waves**: relaunch with `wave_hs_m:=0.05`; verify `~/wave_elevation` oscillates.

## 11) Quickstart with `setup_env.sh`

From the repo root:

```bash
source scripts/setup_env.sh
colcon build --packages-select chrono_flap_sim
source install/setup.bash
ros2 launch chrono_flap_sim sil_mode.launch.py \
  seastack_h5_path:=$HOME/SEA-Stack/build/data/demos/oswec/hydroData/oswec.h5
```

`scripts/setup_env.sh` exports `Chrono_DIR`, `SEAStack_DIR`, and prepends the
correct prefixes to `CMAKE_PREFIX_PATH`. See its header for env-var overrides.
